## 🚀 Gradient Boosting Algorithms — Learn & Build

Welcome! This repo consolidates all code, notes, and insights from the [Getting Started with Gradient Boosting Algorithms](https://apxml.com/courses/getting-started-with-gradient-boosting-algorithms) course hosted by ApX Machine Learning.

----

The goal is to learn:
* What gradient boosting is
* How it works under the hood
* How to implement it from scratch
*& How to use established libraries (Scikit-Learn, XGBoost, LightGBM, CatBoost)
* How to tune and interpret models

----

📚 Course Structure & Content

The course covers the following major areas:

1. **Boosting Fundamentals**
   * What is boosting (ensemble of weak learners)?
   * Weak vs strong learners
   * Bias-variance tradeoff in ensembles

⸻

2. **Gradient Boosting Machine (GBM)**
   * Intuition: iterative error correction
   * Role of gradients and pseudo-residuals
   * Loss functions (MSE, Log Loss, etc.)
   * Why trees are commonly used as weak learners
   * Hands-on: GBM from scratch in Python

⸻

3. **Scikit-Learn Implementations**
   * GradientBoostingRegressor & GradientBoostingClassifier
  * Fitting and prediction examples
  * Interpreting model parameters
  * Feature importance & Partial Dependence Plots

⸻

4. **Advanced Boosting Libraries**
   * XGBoost — optimized and regularised GBM implementation
  * LightGBM — fast, efficient, tree-based GBM algorithm
  * CatBoost — GBM with excellent handling of categorical features

⸻

5. Hyperparameter Tuning & Optimization
   * Key hyperparameters: learning rate, number of estimators, tree depth, subsampling
   * Structured tuning strategies (Grid Search, Random Search, cross-validation)
   * Tools such as GridSearchCV, early stopping, and advanced search frameworks. ￼
